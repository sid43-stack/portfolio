# Siddharth Goyal - Personal Portfolio & B2B Technology Profile

A modern, high-performance personal portfolio website built with React 19, TypeScript, Vite, and Tailwind CSS. Tailored for corporate, technical, and customer-facing B2B roles.

🔗 **Live Deployment**: [https://sid43-stack.github.io/portfolio/](https://sid43-stack.github.io/portfolio/)

---

## 🚀 Key Highlights & Sections

1. **Candidate Telemetry & Live Console**: Interactive telemetry header, system stats, and quick recruiter filters.
2. **Executive Summary & Pitch**: Crisp profile, audio voice pitch preview, and one-click copyable elevator pitch.
3. **Interactive Scenario Engine**: Real-world B2B troubleshooting simulations (escalation handling, technical triage, SLA adherence).
4. **Technology to B2B Value Matrix**: Demonstrating how technical proficiency (Python, APIs, SQL, Automation) translates into enterprise client satisfaction and operational efficiency.
5. **Architectural Project Deep-Dives**: Detailed case studies with architecture workflows and business impacts.
6. **Academic & Performance Telemetry**: BCA coursework, academic standing (GPA 8.4), and core domain competencies.
7. **Direct Contact & Verification**: Multi-channel reach with downloadable resume.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 8](https://vite.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [GitHub Actions](https://github.com/features/actions) & GitHub Pages / Vercel

---

## 📦 Local Development

```bash
# Clone the repository
git clone https://github.com/sid43-stack/portfolio.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
